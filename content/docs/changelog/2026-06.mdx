Added Stacked Sections for pinned chapter scroll stories. Wave 1 widgets got Apple-style type hierarchy and props-driven demos. Card Spread was rebuilt for deck, peek, and throw-on-click motion. Card Stack was trimmed to bare-bones stack mechanics with profile UI moved to the Storybook demo. Four oversized widgets left the public catalog, and the internal widget standards doc was removed from contributing.


## Site quality

Ran a site-wide react-doctor remediation pass and cleared the scan to zero errors and zero warnings across the component library and docs app. Consolidated Motion imports behind a shared `LazyMotion` helper with the lazy `domAnimation` bundle, tightened pnpm install behavior, and added a GitHub Actions workflow that runs react-doctor on pull requests and pushes to main.

## Documentation

Added `robots.txt`, expanded the sitemap to include blog and secondary routes, and wired dedicated metadata for the home and 404 pages.

Published [Top Animated React Buttons (2026)](/docs/guides/animated-react-buttons) as a curated button hub with registry install commands.

Added a Resources page at `/resources` — 26 curated design galleries with grateful, first-person copy and OG previews, linked from the footer only. Redesigned the site footer with structured columns, social links, and a resources callout.

Unpublished Calendar Widget, Music Stack Interaction, Team Clock, and Video Chat from the docs and shadcn registry so the widget overview lists only glance-sized tiles. Removed the internal widget catalog standards page from contributing. Added `useIsMobile` for responsive docs and demo behavior. Widget overview now tracks published entries only and places Fund Widget in the square section.

Split the Skeleton category into six dedicated docs pages (Receipt, List, Wide Card, Cookie Banner, Code, Report) so the category appears on `/components` and each placeholder has its own preview, install steps, and usage notes.
