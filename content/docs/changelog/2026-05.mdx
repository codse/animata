title: May 2026
description: Tailwind CSS 4.3 and shadcn/ui component refresh with unified Radix imports.
date: 2026-05-21

Upgraded the docs and site toolchain dependencies. Tailwind CSS moved to 4.3 (with matching `@tailwindcss/postcss`), and `tailwind-merge` to 3.6. All seventeen installed shadcn/ui primitives were re-synced from the official registry with `npx shadcn@latest add <component> -o`, keeping `@radix-ui/react-*` imports per the new-york style (not the experimental unified `radix-ui` migration). Command palette and dialog were refreshed together so `cmdk` and `@radix-ui/react-dialog` types stay aligned. The `shadcn:add` script now calls `shadcn@latest` instead of the deprecated `shadcn-ui` CLI. Fixed the command palette dialog scaling from the top-left corner by dropping legacy `slide-in-from-*` transforms on `DialogContent` that conflict with centered `translate` under Tailwind v4 and `tw-animate-css`.
