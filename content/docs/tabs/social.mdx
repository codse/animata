### Manual

<Steps>
<Step>Install dependencies</Step>

```bash
npm install motion lucide-react
```

<Step>Run the following command</Step>

It will create a new file called `social.tsx` inside the `components/animata/tabs` directory.

```bash
mkdir -p components/animata/tabs && touch components/animata/tabs/social.tsx
```

<Step>Paste the code</Step>

Open the newly created file and paste the following code:

```jsx file=<rootDir>/animata/tabs/social.tsx

```
