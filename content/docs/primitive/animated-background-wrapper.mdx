## Usage

Wrap any section with the component. It renders the aurora variant by default with no props needed.

```tsx
import AnimatedBackgroundWrapper from "@/animata/primitive/animated-background-wrapper";

export default function Hero() {
  return (
    <AnimatedBackgroundWrapper variant="aurora" intensity="medium">
      <div className="py-20 text-center">
        <h1>Your content here</h1>
      </div>
    </AnimatedBackgroundWrapper>
  );
}
```

## Variants

| Variant | Effect | Best for |
| --- | --- | --- |
| `aurora` | Drifting colour blobs (default) | Hero sections, dark backgrounds |
| `beam` | Diagonal spotlight sweep | CTAs, feature highlights |
| `grid` | 3-D perspective grid | Technical / dev-focused sections |
| `particles` | Floating dust particles | Full-page backgrounds |

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `variant` | `"aurora" \| "beam" \| "grid" \| "particles"` | `"aurora"` | Background effect |
| `intensity` | `"subtle" \| "medium" \| "strong"` | `"medium"` | Opacity multiplier (0.5× / 1× / 1.5×) |
| `className` | `string` | — | Extra classes on the wrapper |
| `children` | `ReactNode` | showcase | Content rendered above the background |
